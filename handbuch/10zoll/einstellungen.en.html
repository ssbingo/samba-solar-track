1About this manual

This manual guides you from the first switch-on of the controller to a fully set-up tracker. You need no prior knowledge. Every technical term is in the glossary.

What this manual covers

  • The setup at the display: language, operating mode, anemometer, network, time, remote access, design, sound, screen and firmware (Chapter 4).
  • The setup program: on the finished rack it checks every function and every travel path step by step. Only after that does the system track by itself (Chapter 5).
  • Location, orientation, sun and night: where the rack stands, which way it faces, when it is night (Chapter 6).
  • Every adjustable value with its meaning, default, limits, a recommendation for the Samba Solar Rack and a guide for any other system (Chapter 7).
  • What you can set in the browser and what only works at the display (Chapter 8).

What it does not cover

  • Assembling the mechanics. For that, see the assembly manual of the Samba Solar Rack (website and shop) or the instructions for your frame.
  • Connecting the cables. For that, see the wiring manual (German only; file verkabelung.html in the same folder).
  • The circuit boards, flashing the firmware and checking the hardware. For that, see the manual for assembly and operation (file index.html).
Everything must be connected first

Only start with this manual once the rack is assembled, the wiring is finished and checked (wiring manual, German only) and the controller has power. The setup program moves the rack.

One or two axes: how the sections are marked

Samba Solar Track works in two operating modes. Most users have two axes; both operating modes are described equally here. Anything that does not apply to both carries a label:

↕

1 axis

Operating mode “vertical only”. The rack only changes its tilt (elevation). This is how the Samba Solar Rack works.

⟲

2 axes

Operating mode “vertical + horizontal”. The rack tilts and also turns from east to west (azimuth).

✓

both

Applies to every system. Sections without a label also apply to both.

○

optional

May be skipped. The controller also works safely without this item.

2The way to a finished system

The controller is set up in four stages. The order is fixed: without setup no drive moves, without the setup program the system does not track by itself.

  1. Choose the languageAt first switch-on the language selection appears by itself, set to English by default. The choice applies immediately. Result: All texts are in your language. Chapter 4.1
  2. Setup: operating mode and anemometerYou choose 1 or 2 axes and your anemometer and tap SAVE + RESTART. Result: The controller restarts. From now on storm protection and anemometer monitoring are active. Chapter 4.2
  3. Setup programIt opens by itself after the restart and checks everything on the rack one after the other: board, anemometer, travel directions, travel paths, sun sensor, test run. Result: “Done! All checks are passed.” The automatic is enabled. Chapter 5
  4. Fine-tuningLocation and orientation, tracking values, sound, screen, remote access. Result: The system works the way you want. Chapter 6 and 7
How long does it take?

The setup takes a few minutes. Take your time for the setup program and choose a day with little wind and some sun: the drives travel the whole way several times and need pauses in between (duty cycle, Chapter 7). You can interrupt the setup program at any time with CONTINUE LATER and resume later at the same point.

3Axes and directions

Before the rack moves for the first time: these words come up again and again on the display. They apply to every rack.

One axis: the tilt (elevation) 1 axis also with 2 axes

  • STEEPER: the panels rise, their top edge goes up. Needed in the morning, in the evening and in winter, when the sun is low.
  • FLATTER: the panels lie down, towards horizontal. Needed at midday in summer, in a storm and at night.
  • The buttons on the display are called STEEPER and FLATTER. The terminals of the board are still called UP and DOWN. Which terminal means “flatter” is set by the value “Flat position is in UP direction”; the setup program checks it.

Two axes: tilt and rotation (azimuth) 2 axes

  • EAST: the rack turns towards the morning sun. On the board output this is the EAST contact (terminal J5).
  • WEST: the rack turns towards the evening sun (WEST contact, terminal J6).
  • Only one axis moves at a time. This spares the power supply.
  • The Samba Solar Rack only has the tilt. Anyone with two axes uses a different frame; for that, every value in Chapter 7 says how to find the right value.

Flat position: the safe position

4Setup at the display

The setup appears by itself at the first switch-on. Later you reach it via the gear wheel at the top right of the dashboard. If the device is already set up, the controller including storm protection keeps working while the setup is open.

Without setup nothing moves, and there is no storm protection

As long as operating mode and anemometer are not saved, all outputs stay off. The BEREIT (ready) indicator light flashes. So set up the controller right after the first switch-on.

4.1 Language both

  1. Tap a languageThe choices are English, Deutsch, Français, Español, Nederlands, Português and Polski. Result: The texts change immediately, without a restart. The choice is saved.
  2. Tap NEXTResult: The setup appears.

Later you change the language with the button showing the name of the language at the top right of the setup (for example “ENGLISH …”). The web interface always shows the language of the display.

4.2 Operating mode and anemometer both

  1. Choose the operating modeVERTICAL ONLY (1 axis: elevation) or VERTICAL + HORIZONTAL (2 axes: elevation and azimuth). Nothing is selected by default. Result: The selected button is blue with a yellow border.
  2. Choose the anemometerWIND SPEED ONLY or WIND + WIND DIRECTION. Both are anemometers with an RS485 output (Modbus RTU); other outputs (pulse, 0–10 V, 4–20 mA) are not supported. Result: The button is marked.
  3. Tap SAVE + RESTARTThe button only works once both are selected. Result: All outputs switch off, the controller restarts, then the setup program opens.

1 axis vertical only

The azimuth outputs always stay open. The display has no EAST and WEST buttons; instead there is the TILT card with fixed angles (0°, 30°, 60° and two preset angles). Of the sun sensor, only north versus south counts.

2 axes vertical + horizontal

Both axes are tracked, always one after the other. The display has STEEPER, FLATTER, EAST and WEST. The sun sensor is evaluated on all four sides. There is no TILT card with fixed angles.

Which anemometer?

For the Samba Solar Rack, two separate sensors on the same bus are intended: wind speed (address 3) and wind direction (address 4), i.e. WIND + WIND DIRECTION. The wind direction is only displayed and logged; it affects neither tracking nor storm protection. Anyone with only a speed sensor chooses WIND SPEED ONLY.

Changing later

You can change operating mode and anemometer at any time. New settings only apply after SAVE + RESTART; until then the controller keeps working with the previous ones. CANCEL discards the selection. If you have changed the operating mode, check the system again afterwards: SETUP PROGRAM → CHECK EVERYTHING AGAIN (Chapter 5.4).

4.4 Network: Wi-Fi, hotspot and time optional

Wi-Fi is off by default. The controller never needs it: tracking and storm protection work just the same without a network. With Wi-Fi, however, you get the exact time (then the device knows sunrise and sunset), the web interface for phone and PC, and the check for new firmware.

No Wi-Fi, no time

The board has no clock of its own with battery backup. The time only comes over Wi-Fi from a time server. Without Wi-Fi the device detects night by the brightness (Chapter 6).

Way A: type it in at the display

  1. Setup → NETWORKResult: The NETWORK screen appears, “WI-FI OFF” at the top right.
  2. Switch on Wi-FiTap the WI-FI switch. Result: The switch is blue.
  3. Enter the Wi-Fi name and passwordTap the field, type with the on-screen keyboard, confirm with the tick. The name has 1 to 32 characters, the password is empty or has 8 to 63 characters. The keyboard has no umlauts or accents; for such names use way B. Result: Name and password are in the fields.
  4. Check the timeTIME button. Default: time server pool.ntp.org, time zone Germany (CET/CEST). If you live in a different time zone, choose it under SUGGESTIONS and tap APPLY. Result: You are back on the NETWORK screen.
  5. SAVE + RESTARTResult: All outputs switch off, the device restarts and connects. The Wi-Fi symbol appears in the header: white = connected, yellow = no connection. Shortly afterwards the time appears to its left.

Way B: via the setup hotspot (with your phone)

  1. NETWORK → START HOTSPOTResult: The device opens its own Wi-Fi “Samba-Setup-” with four characters. Name and password are shown on the display; the password is different at every start.
  2. Connect your phone to this Wi-Fi and open http://192.168.4.1 in the browserResult: The setup page appears (picture on the right) with a list of the Wi-Fi networks found.
  3. Choose the Wi-Fi, enter the password and device name, saveThe device name consists of a–z, 0–9 and hyphen, by default samba-solar-track. Result: The device restarts after 1.5 s and connects to your Wi-Fi.

The hotspot ends by itself after 10 minutes. While it is running, the Wi-Fi connection rests.

Where do I find the device on the network?

At the address shown on the NETWORK screen, or at http://samba-solar-track.local (or the device name you have given it). If the connection fails, the device tries again every 30 seconds, without end.

4.5 Remote access: log in your phone, lock remote control optional

  • QR code: appears as soon as Wi-Fi is connected. Scan it with your phone; the browser opens the web interface and is logged in. Without logging in, the browser can only watch.
  • Token: a secret key of 32 characters that the device creates itself. On the PC you enter it in the web interface under ENTER TOKEN; the NETWORK screen shows it in four blocks.
  • REMOTE CONTROL: when locked, the device accepts no remote command and no change; displays keep updating. Lock it when someone is working on the mechanics. Applies immediately.
  • RENEW TOKEN: if a phone has been lost. With a confirmation prompt; afterwards everyone has to log in again. Applies immediately.

4.9 Firmware optional

With Wi-Fi the device checks once a day whether there is newer firmware. It never installs by itself, only when you tap INSTALL and confirm the prompt. Before writing, the elevation moves flat; while writing, control and storm protection pause briefly. Then the device restarts and checks itself; if that fails, it returns to the previous firmware. The saved settings are kept.

4.10 Simulation: trying out without the board

With the simulation you can try out operation without the RearCircuitBoard_10 board, without drives and without sensors, for example at your desk. It can only be switched on when the board is not plugged in, and it needs a confirmation. The display shows the simulation permanently. If the board is plugged in at start, a saved simulation switches itself off. The setup program can also be played through in the simulation; its test report is then marked “SIMULATION”.

After the simulation the setup program starts again on the real rack

A setup program that was only completed in the simulation does not count on the real rack. When the device starts for the first time with the board plugged in, the setup program starts again at step 1 by itself. Until it is passed on the real rack, the automatic stays locked (purple band “SETUP PROGRAM MISSING”); storm protection and parking keep working. You need to do nothing for this except go through the setup program on the rack (Chapter 5).

5The setup program

The setup program checks everything on the finished rack once that matters for safe operation: board, anemometer, travel directions, travel paths, sun sensor and the automatic. Where a person has to judge, it asks. Where the device can measure itself, it measures. Only when all mandatory steps are passed does the system track by itself.

Tested on the PC only

The setup program is implemented in firmware 0.7.0 and checked with automatic tests and in the simulation, but has never run on a real rack. There are no limits yet for travel times, Hall steps and angles (decision E-S3): “passed” means end position reached or confirmed by you; the measured values go into the test report.

5.1 Before you begin

  • Little wind. In a storm every travel test is cancelled, and the rack moves flat.
  • Daylight or a bright lamp. Sun sensor and test run need light (at least the day threshold, by default sum 6000).
  • Two people are better than one. One stands at the display, the other watches the rack. If the display is far away, use a phone to talk to each other.
  • A clear view of the rack and of the anemometer; a ladder for the anemometer if it is mounted high (only climb up the rack with the power supply switched off if you get into the swivel range).
  • A phone with an inclinometer app (spirit level) for the step “Move to angle” 1 axis and a compass (an app will do) for the location.

How it opens

  • After the setup is saved, it opens by itself.
  • If you leave it (CONTINUE LATER), the dashboard shows the purple band “SETUP PROGRAM MISSING: AUTOMATIC LOCKED – TAP HERE TO CONTINUE” at the bottom. Tapping it opens it again at the same point.
  • Also via the gear wheel → SETTINGS → COMMISSIONING → green line SETUP PROGRAM (CHECK EVERYTHING).
  • The progress is saved, even across a restart or power failure.

4Anemometer both

What you see

A wind wheel from above; at the bottom right in yellow “Wind now … km/h (highest …)”.

What you do
  1. Tap START.
  2. Turn the wind wheel firmly by hand.
  3. NEXT.
  4. Only with wind direction: point the vane north and see whether the display shows about N (0°); YES or NO.
What must happen

When turning, the reading rises by at least 2 km/h, and the text changes to “Turning detected”. The direction shows about north.

If not

“The wind wheel has not been turned yet.”: turn it more firmly. No number: the anemometer is not responding; check the wiring and the anemometer data. Wrong direction (NO): check the mounting and north mark of the anemometer, then REPEAT.

5Direction of the flat position both

The most important step: it decides where the rack moves in a storm (Chapter 3).

What you see

On the left a sketch “This is how it should look: FLATTER”, on the right the instructions and a large FLATTER button.

What you do
  1. NEXT.
  2. Hold FLATTER and watch the rack. Releasing it stops at once; after 5 s it stops by itself.
  3. YES, FLATTER if the panels have moved towards horizontal, otherwise NO.
  4. Watch until the rack stops by itself.
What must happen

The rack becomes flatter and then moves to the end position. “The flat position is checked. From now on the storm protection keeps the rack safe.”

If not

With NO the device switches the direction itself (value “Flat position is in UP direction”): “Good that we checked”, then REPEAT. If nothing moved at all: check the power supply at the rack, the wiring of the contacts, the sync controller (momentary mode?). If the rack is already fully flat, the device asks straight away whether it is flat.

Without limit switches the flat move takes the full maximum run time

If “Elevation limit switch fitted” is set to no, the controller waits for the whole maximum run time, even if the rack has already stopped (run-time end position). On the Samba Solar Rack that is 90 s. With a Hall tap the move ends about 1 s after the pulses stop.

6Tilt travel

1 axis CALIBRATE TRAVEL TIME

The device measures how long the rack takes from fully flat to fully steep and back. From this it later knows every angle. Tap CALIBRATE TRAVEL TIME; a separate screen guides you in four steps (pictures below). Then you come back and tap NEXT.

2 axes fully steep and back

START: the rack moves fully steep to the end stop, then fully flat to the end stop. The device measures both times. Then it asks whether the rack moved fully steep and fully flat again without catching or bumping.

1 axis The four steps of CALIBRATE TRAVEL TIME

What you see

1 axis the CALIBRATE TRAVEL TIME button. 2 axes the running travel time, then the question.

What you do

1 axis go through CALIBRATE TRAVEL TIME, APPLY, back, NEXT. 2 axes START, watch, YES or NO.

What must happen

The rack reaches both end positions without catching or bumping. 1 axis “Both times are plausible”: each at least 10 s, shorter than 0.9 × maximum run time, UP and DOWN at most in a ratio of 1 : 2.

If not

“The travel time has not been calibrated yet.”: calibrate first. Cancelled with “MAX. RUN TIME TOO SHORT OR ARRIVED NOT TAPPED”: increase the maximum run time. NO with 2 axes: check mechanics and drive (assembly manual of the rack), then REPEAT.

With Hall tap 1 axis

If “Hall tap present” is set to yes, the line is called “CALIBRATE: TRAVEL TIME AND HALL STEPS”. The measuring moves then end by themselves and count the Hall steps; plausible are at least 1000 steps each, UP and DOWN at most 3 % apart. If the rejection reads “HALL COUNTS BACKWARDS”, set “Invert Hall count direction” to yes.

7Rotation east – west 2 axes

What you see

On the left a top view with a compass (yellow: direction the panels face), on the right the instructions and the EAST button.

What you do
  1. NEXT, then hold EAST (5 s at most).
  2. YES, TO THE EAST if the rack has turned towards the morning sun.
  3. Watch: the rack turns fully east, fully west and back east.
What must happen

All three moves reach their end stop. “Rotation checked. The rack is in the morning position.”

If not

NO: this cannot be changed by a setting. Switch off the power supply, swap the plugs at J5 and J6 (wiring manual, German only), switch on, REPEAT. No movement: check the power supply and wiring of the azimuth drive.

+Reset of the sync controller only if set

This step only exists if a reset output is selected in step 2. It comes after the travel path (with 2 axes after the rotation). There is no picture of its own for it yet; the band in the dashboard shows the progress, as with a reset via SETTINGS.

What you see

“The sync controller of the drives has a reset input. In a moment the device triggers it.” and the TRIGGER RESET button.

What you do

TRIGGER RESET, watch. With 2 axes and two resets, both run one after the other.

What must happen

The sync controller fully retracts the drives (on the rack: flat). “Reset checked.”

If not

“Reset not possible (check connection or chip).”: it did not start within 20 s; check terminal J23 or J5 and the value reset. “Reset aborted”: the cause is in the status bar; then REPEAT.

Assumption

The duration of the reset pulse (5 s) and the behaviour of the sync controller afterwards have not yet been measured on the rack.

7Move to angle 1 axis

What you see

“Now the rack moves to 30 degrees.” and the MOVE TO 30 DEGREES button.

What you do

Tap the button, wait. Then lay the phone flat on a panel, read the angle, type it in (0 to 90), tick.

What must happen

The rack stops at about 30°. “Angle recorded. It is in the test report.”

If not

8Sun sensor

What you see

The sensor from above with four fields. The side you are to shade is marked.

What you do

START. Then shade the named side, wait until the device detects it, take your hand away. 1 axis SOUTH, then NORTH. 2 axes EAST, WEST, SOUTH, NORTH.

What must happen

6.3 Orientation of the rack 1 axis

A rack with one axis cannot turn. If it does not face exactly south, the sun is “in front” of the rack at different times. So that the device calculates correctly, you tell it which way your rack faces. With two axes this value is not needed, because the azimuth follows the sun anyway.

Under thick cloud, the sun sensor cannot see a direction. If this switch is on, the elevation then moves to the calculated best angle (as with tilt on command), and the status bar shows “CLOUDY: …”. Assumption

The threshold of 20000 is an estimate. On an overcast day, watch the brightness in the SUN SENSOR card (sum of the four values) and set the threshold slightly above it (Chapter 7).

10Terms simply explained

Axis
A direction in which the rack can move. Elevation = tilt, azimuth = rotation.
Automatic
The controller tracks the rack to the sun by itself, moves to the night position at night and back in the morning. AUTOMATIC switch in the header.
Azimuth
The east-to-west rotation, only with 2 axes. Also: the compass direction of the sun in degrees.
Gust
Here: the average wind speed over 3 seconds. If it is above the storm threshold, it counts as a storm.
Decimal degrees
Notation for latitude and longitude with decimal places, for example 51.0504 instead of 51° 3′ 1″.
Calibration
The device measures the travel time (and, with a Hall tap, the Hall steps) over the full travel of the tilt. Only with 1 axis.
Duty cycle
How long a drive may run in relation to the pause without overheating. Here 10 % and at most 120 s continuously.
Setup
The screen with operating mode and anemometer. Without a saved setup, no drive moves.
Elevation
The tilt of the module between flat and steep.
End position
The end of the travel in one direction.
Limit switches
A switch at the end of the travel that opens when reached (normally closed, NC). For the controller, open means: direction blocked.
Flat position
The flat position of the module. Also the storm position and night position (0 position).
Frame G1, G2
The designs of the Samba Solar Racks. They determine how the travel of the drive is turned into an angle.
Hall tap, Hall steps
Many drives have a Hall sensor that gives pulses while moving. The HallTapBoard passes them on to the circuit board. A Hall step is one counted edge of these pulses.
Hold time
How long the rack stays flat after the last storm gust.
Manual mode
Automatic off: the rack only moves while you hold a move button.
Max. run time
Longest permitted continuous move. Without limit switches, the controller uses it to detect the end position.
Hotspot
A separate, temporary Wi-Fi network of the device for entering the Wi-Fi details with a phone.
Run-time end position
Without limit switches: after the full max. run time in one go, the end position counts as reached.
Modbus, RS485
The way the anemometer talks to the circuit board over two wires. Each sensor on the bus has an address.
NTP, time server
A service on the internet from which the device fetches the exact time.
0 position
The night position: elevation flat.
Test run
Last test step of the setup program: the automatic must turn the offset rack back to the sun.
Test report
Report with all results and measured values of the setup program, in the web interface as a designed sheet (PDF) or as a text file; the last three are kept in the device.
Reset of the sync controller
A short contact between RST and COM with which some sync controllers release themselves again after a fault; in doing so they fully retract the drives.
Setup program
The guided check of the whole installation after the setup. Only then is the automatic enabled.
Simulation
Operation without circuit board with a simulated rack, only for trying things out.
Sun sensor
A sensor with four sides (east, west, south, north). From the difference in brightness the controller detects where the sun is.
Storm threshold
Wind speed from which the rack moves flat.
Sync controller
A control unit that makes the two drives of an axis move at exactly the same speed (for example BST-KZQ-15A-2). The circuit board “presses” its buttons.
Token
Secret key of 32 characters. Whoever has it may operate the device remotely.
Dead time
Pause before a change of direction.
Web interface
The control page in the browser of a phone or PC, in the home Wi-Fi.
